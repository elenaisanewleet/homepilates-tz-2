# HomePilates

[Открыть демо на Vercel](https://homepilates-tz-2.vercel.app/) · [Пакет блоков для Tilda](tilda/) · [Проверки](QA.md)

Девять страниц по ТЗ на доработку classes.homepilates.ru. Тексты, цены и контакты дословно из ТЗ (`data/content.json`), оформление — собственная система «Атлас движения». Демо открыто для просмотра с `noindex`. Подключены рабочие виджеты Mobifitness (расписание, личный кабинет, магазин сертификатов), отзывы и карта Яндекса. Метрика 51299566 загружается только после согласия на аналитические cookie. Форма обратной связи в превью открывает почтовую программу; в Tilda её заменяет штатная форма, заявки уходят в amoCRM.

## Локальный просмотр

Требуется Python 3.9 или новее. Команды из корня проекта.

```sh
python3 tools/build.py
python3 tools/check.py
python3 -m http.server 8000 --directory public
```

Откройте [локальную главную](http://localhost:8000/). Тексты ТЗ в `data/content.json`, разметка страниц в `src/pages.py`, оформление в `src/theme.css`, меню, cookie, Метрика и виджеты в `src/site.js`, фото в `src/photos/`. `data/PRICING_SOURCE.csv` и `data/PRICING_AUDIT.csv` — прежний разбор цен, сайт их больше не использует. При изменениях пересоберите HTML и добавьте в коммит исходники, `public/` и `tilda/`. Vercel публикует только `public/` с корнем проекта в корне репозитория. Сборка и установка пакетов на Vercel не требуются.

## Передача в Tilda

1. Владелец предоставляет роль редактора для проекта `classes.homepilates.ru`. Сделайте копии существующих страниц, сохраните список URL, якорей, метаданных, форм и действующих маршрутов записи. Согласуйте карту переходов и способ отката.
2. Создайте тестовые копии восьми информационных страниц и отдельного кабинета. Общий стиль из `tilda/shared-head.html` вставьте в HTML-код внутри HEAD сайта. Селекторы ограничены контейнером `#hp-site`.
3. Добавьте по одному блоку T123 на страницу. Скопируйте в него содержимое одноимённого файла из `tilda/`. Для главной используйте `home.html`. Каждый блок содержит общие шапку и футер, разметку страницы и скрипт сайта: меню, cookie, Метрику по согласию и подключение виджета. Фото в блоках берутся через jsDelivr из этого публичного репозитория; после загрузки фото в Tilda замените адреса. Отключите дублирующие шапку/футер на тестовой копии. Иллюстрация включена в HTML. [Справка Tilda](https://help.tilda.cc/html)
4. Перенесите адреса, title, description и canonical из `tilda/seo.csv` в настройки страниц. До приёмки закройте тестовые страницы от индексации. В production включайте индексацию согласованных публичных страниц, кабинет закройте отдельно. Проверьте штатные robots и sitemap Tilda. Перенаправления 301 нужны только для реально удалённых URL после инвентаризации.
5. Виджеты Mobifitness (код 308687, клуб 9514) уже встроены: скрипт монтирует их в блок `.mobi` — расписание сразу, остальные при подлёте к экрану. Проверьте их на опубликованной тестовой странице. На каждой странице допустим только один виджет. На стоимости оставьте ссылку к записи. [Инструкция Mobifitness](https://mobifitness.usedocs.com/article/48525)
6. До включения записи владелец проверяет модули, SMS и тестовый номер. На опубликованной тестовой странице проверьте реальные места, пустую выдачу, ошибку загрузки, вход, повторную попытку, запись, списание, перенос, отмену и историю. При сбое показывайте связь с администратором.
7. Для продажи абонементов подтвердите эквайринг, связь с Mobifitness и фискализацию. По отдельному согласованию проведите тест успеха, отказа и возврата с проверкой начисления на балансе и чека. Для сертификатов отдельно проверьте доставку кода, однократную активацию и защиту от повторного использования. [Интеграция КОМТЕТ](https://kassa.komtet.ru/mobifitness)
8. До включения формы владелец согласует политику, согласие, получателя и доставку тестовой заявки. Затем замените `form.feedback` штатным блоком формы Tilda с тем же согласием: HTML-форма внутри T123 обходит amoCRM. Штатное подключение Метрики в Tilda не включайте, иначе счётчик загрузится до согласия. Проверьте сетевые запросы до выбора, после отказа и согласия.
