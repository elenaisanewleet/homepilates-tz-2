# HomePilates

[Открыть демо на Vercel](https://homepilates-tz-2.vercel.app/) · [Пакет блоков для Tilda](tilda/) · [Проверки](QA.md)

Девять страниц по новому HomePilates Codex Handoff. Основной сценарий ведёт от выбора занятия и просмотра цены к контактам студии. Демо открыто для просмотра с `noindex`. Сборка статическая, без внешних шрифтов, трекеров, онлайн-платежей и сбора заявок. Контактные ссылки открывают телефон, почту, карту или соответствующее приложение.

## Локальный просмотр

Требуется Python 3.9 или новее. Команды из корня проекта.

```sh
python3 tools/build.py
python3 tools/check.py
python3 -m http.server 8000 --directory public
```

Откройте [локальную главную](http://localhost:8000/). Контент и навигация находятся в `src/pages.py`, оформление в `src/theme.css`, управление меню в `src/menu.js`. Исходные прайсы находятся в `data/`. При изменениях пересоберите HTML и добавьте в коммит исходники, `public/` и `tilda/`. Vercel публикует только `public/` с корнем проекта в корне репозитория. Сборка и установка пакетов на Vercel не требуются.

## Передача в Tilda

1. Владелец предоставляет роль редактора для проекта `classes.homepilates.ru`. Сделайте копии существующих страниц, сохраните список URL, якорей, метаданных, форм и действующих маршрутов записи. Согласуйте карту переходов и способ отката.
2. Создайте тестовые копии восьми информационных страниц и отдельного кабинета. Общий стиль из `tilda/shared-head.html` вставьте в HTML-код внутри HEAD сайта. Селекторы ограничены контейнером `#hp-site`.
3. Добавьте по одному блоку T123 на страницу. Скопируйте в него содержимое одноимённого файла из `tilda/`. Для главной используйте `home.html`. Каждый блок содержит общие шапку и футер, разметку страницы и скрипт меню. Отключите дублирующие шапку/футер на тестовой копии. Иллюстрация включена в HTML. [Справка Tilda](https://help.tilda.cc/html)
4. Перенесите адреса, title, description и canonical из `tilda/seo.csv` в настройки страниц. До приёмки закройте тестовые страницы от индексации. В production включайте индексацию согласованных публичных страниц, кабинет закройте отдельно. Проверьте штатные robots и sitemap Tilda. Перенаправления 301 нужны только для реально удалённых URL после инвентаризации.
5. Для расписания и кабинета замените демо-панели `section.status-card` на выделенное место для интеграции. Можно разбить T123 на самостоятельные секции и поместить виджет отдельным T123 между ними, сохранив валидную разметку. Вариант для одной страницы — вставить обе связанные строки кода, выданные Mobifitness, в место демо-панели внутри T123 и проверить результат на опубликованной тестовой странице. Стили виджета проверить отдельно. На каждой странице допустим только один виджет. На стоимости оставьте ссылку к записи. [Инструкция Mobifitness](https://mobifitness.usedocs.com/article/48525)
6. До включения записи владелец проверяет модули, SMS и тестовый номер. На опубликованной тестовой странице проверьте реальные места, пустую выдачу, ошибку загрузки, вход, повторную попытку, запись, списание, перенос, отмену и историю. При сбое показывайте связь с администратором.
7. Для продажи абонементов подтвердите эквайринг, связь с Mobifitness и фискализацию. По отдельному согласованию проведите тест успеха, отказа и возврата с проверкой начисления на балансе и чека. Для сертификатов отдельно проверьте доставку кода, однократную активацию и защиту от повторного использования. [Интеграция КОМТЕТ](https://kassa.komtet.ru/mobifitness)
8. До включения формы владелец согласует политику, согласие, получателя и доставку тестовой заявки. Затем добавьте форму Tilda, защиту от спама и подтверждение только после ответа сервера. Настройте категории согласия и Метрику, проверьте сетевые запросы до выбора, после отказа и согласия.

## Материалы к утверждению

| Кто | Следующий шаг перед запуском на Tilda |
| --- | --- |
| Владелец | Утвердить отдельный кабинет, вместимость мини-групп и фактические номера для звонков и мессенджеров. В демо сохранены разные номера из handoff. |
| Владелец | Сверить 12 расхождений по 25 формулам в `data/PRICING_AUDIT.csv`, сроки заморозок, номиналы и срок действия сертификатов. Демо выводит итоговые суммы из исходного CSV. |
| Студия | Передать утверждённый логотип, реальные фото с правами, биографии, текст шести шагов, источник цитаты и разрешённый источник отзывов. Подтвердить ссылки MAX и приложений. |
| Редактор и владелец | Проверить тексты о нагрузке, восстановлении и правилах переноса. Согласовать юридические материалы, получателей заявок и аналитику. |
| Администраторы Tilda, Mobifitness и оплаты | Предоставить ограниченные доступы отдельно от Git, провести приёмку полного цикла на опубликованной тестовой странице. |

Основные синий и оливковый цвета взяты из нового ТЗ. Визуальный ориентир — [спецификация Forner Studio от OpenDesign](https://www.opendesign.cc/en/sites/forner-studio). Схема реформера и графический знак созданы для демо. Неподтверждённые фото, биографии, отзывы и цитата ожидают материалов студии. Дополнительный домен Vercel используется только для демо.
